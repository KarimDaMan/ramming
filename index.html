Rammerhead — one-click deploy

This repo is configured to deploy Rammerhead as a Docker service on Render's free tier. GitHub Pages can't run Node, so the actual proxy lives on Render; this page is just the launcher.

Deploy

Deploy to Render

  1. Click the button. Sign in to Render (free, GitHub login works).
  2. Render reads render.yaml and builds the Dockerfile. First build takes ~3-5 minutes.
  3. You'll get a URL like https://rammerhead-xxxx.onrender.com. That URL is your Rammerhead instance.

Heads-up about the free tier

  • Render's free web services spin down after 15 minutes of inactivity. The first request after that takes ~30s to wake. For an always-on instance use Fly.io, Koyeb, or a cheap VPS.
  • Some hosts may flag/suspend public proxies under their AUP — Render hasn't been aggressive about it but it's not guaranteed.

Files in this repo

  • Dockerfile — clones Rammerhead, installs deps, runs it.
  • start.sh — patches config.js to bind 0.0.0.0 on the platform-provided $PORT.
  • render.yaml — Render blueprint for one-click deploy.
  • index.html — this page.

Other hosts

The same Dockerfile works on Fly.io (fly launch), Koyeb, Railway, or any host that runs Docker images. Just point them at this repo.
